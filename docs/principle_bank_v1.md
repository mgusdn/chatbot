# 프바오 원리 중심 표현 뱅크 v1

상세 데이터: [`backend/counsel/principle_bank.json`](../backend/counsel/principle_bank.json)
원본 후보와 안전성 검토: [`principle_reference_candidates_100.md`](./principle_reference_candidates_100.md)

## 선택 구조

```text
세션 메모리 + 마지막 발화
        ↓
principle_id 또는 none
        ↓
표현 모드 하나 선택
├─ reference      속담 또는 사자성어
├─ named_pattern  검증된 현상·개념의 쉬운 설명
└─ social_context 개인 탓을 줄이는 생활·환경 맥락
```

- 판단기의 첫 선택 단위는 표현이 아니라 `principle_id`다.
- `reference`는 `direct`만 기본 허용한다.
- `conditional`은 맥락 적합도가 높을 때만 원문을 허용하고 평소에는 쉬운 풀이를 쓴다.
- `reverse_only`와 `blocked`는 사용자에게 절대 출력하지 않는다.
- 한 턴에는 세 모드 중 하나만 사용하며 적합한 원리가 없으면 `none`을 선택한다.
- 위기·학대·폭력·성적 동의 침해·급성 트라우마·사별·의료·법률 응급 상황에서는 이 뱅크를 끈다.

## 런타임에서 지켜야 할 순서

1. 현재 발화와 세션 메모리로 원리 후보를 최대 3개만 검색한다.
2. 판단기는 후보 중 `principle_id` 하나 또는 `none`을 고른다.
3. 위험 게이트와 최근 사용 이력을 확인한다.
4. `reference`, `named_pattern`, `social_context` 중 한 모드만 선택한다.
5. 공감 뒤 한 문장으로 출력하고 기존의 다음 질문으로 이어 붙인다.

`named_pattern`은 사용자를 분류하는 진단명이 아니라 **설명 후보**다.
`social_context`는 “다들 그래요” 같은 근거 없는 일반화가 아니라 개인의 성격 외에 상황·관계·환경도 함께 보게 하는 문장이다.
