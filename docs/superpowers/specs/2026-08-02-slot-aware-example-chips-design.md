# 슬롯별 예시 칩 설계

## 배경

`frontend/components/counseling/CounselingScreen.tsx`의 입력창 하단 예시 칩(`EXAMPLES` 상수, 12~16행)은 상담 진행 단계와 무관하게 항상 같은 3개 문구(미루는 습관/관계 걱정/잠들기 어려움)를 보여준다. 프바오가 지금 어떤 슬롯(상황/감정/생각/원인/행동/기간·빈도/영향/대인관계/과거 시도/목표/나에게 하고 싶은 말)을 묻고 있는지와 무관하게 동일한 예시가 뜨기 때문에, 슬롯 질문과 예시 답변이 맞지 않는 경우가 생긴다.

## 목표

현재 프바오가 묻고 있는 슬롯에 맞춰 예시 칩의 **문구**를 바꾼다. 칩의 **라벨(미루는 습관/관계 걱정/잠들기 어려움)과 개수(3개)는 모든 슬롯에서 고정**하고, 각 라벨 아래 깔리는 예시 문장만 그 슬롯 질문에 답하는 내용으로 교체한다. 즉 사용자가 하나의 스토리(예: 미루는 습관)를 계속 따라가며 슬롯마다 그 스토리에 맞는 답을 클릭해 넣을 수 있게 한다.

## 데이터 소스

`session.runState.pending_slot`(`frontend/types/counseling.ts:45-53`의 `PublicCounselState.pending_slot`)이 현재 프바오가 채우려는 슬롯 키를 그대로 담고 있다 (`situation`, `emotion`, `thought`, `cause`, `behavior`, `duration`, `impact`, `relationship`, `coping`, `goal`, `self_message` 중 하나, 백엔드 `backend/counsel/state.py`의 `SLOT_ORDER`가 원본).

`pending_slot`이 없는 경우(대화 시작 전 rapport 단계, 가치관 선택 단계 등)는 기존 3개 문구(situation 행과 동일한 문구)를 기본값으로 사용한다.

## 구현 방식

`CounselingScreen.tsx` 내부에 슬롯 키를 key로 하는 맵을 추가한다.

```ts
const SLOT_EXAMPLES: Record<string, readonly (readonly [string, string])[]> = {
  situation: [
    ["미루는 습관", "요즘 해야 할 일이 많은데 자꾸 미루게 돼서 스스로에게 답답해요."],
    ["관계 걱정", "사람들을 만나고 나면 제가 이상하게 말한 것 같아서 계속 걱정돼요."],
    ["잠들기 어려움", "밤에 생각이 많아져서 잠들기가 어렵고 다음 날 너무 피곤해요."],
  ],
  emotion: [
    ["미루는 습관", "일을 또 미뤘다는 생각에 답답하고 저 자신한테 실망스러워요."],
    ["관계 걱정", "그 자리를 떠올리면 창피하고 불안한 마음이 들어요."],
    ["잠들기 어려움", "잠을 설치고 나면 무기력하고 예민해져요."],
  ],
  // ... thought, cause, behavior, duration, impact, relationship, coping, goal, self_message
} as const;

const DEFAULT_EXAMPLES = SLOT_EXAMPLES.situation;

const currentExamples = SLOT_EXAMPLES[session.runState.pending_slot ?? ""] ?? DEFAULT_EXAMPLES;
```

렌더링부(236~238행)는 `EXAMPLES.map(...)` 대신 `currentExamples.map(...)`을 사용하도록 한 줄만 바꾼다. 나머지 클릭 핸들러(`setMessage(example)`)는 그대로 유지한다.

## 전체 슬롯별 문구 (승인됨)

| 슬롯 | 미루는 습관 | 관계 걱정 | 잠들기 어려움 |
|---|---|---|---|
| situation | 요즘 해야 할 일이 많은데 자꾸 미루게 돼서 스스로에게 답답해요. | 사람들을 만나고 나면 제가 이상하게 말한 것 같아서 계속 걱정돼요. | 밤에 생각이 많아져서 잠들기가 어렵고 다음 날 너무 피곤해요. |
| emotion | 일을 또 미뤘다는 생각에 답답하고 저 자신한테 실망스러워요. | 그 자리를 떠올리면 창피하고 불안한 마음이 들어요. | 잠을 설치고 나면 무기력하고 예민해져요. |
| thought | 나는 왜 항상 이렇게 미루기만 할까 하는 생각이 들어요. | 다들 나를 이상하게 봤을 것 같다는 생각이 계속 들어요. | 내일도 못 잘까봐 걱정하는 생각이 머릿속을 떠나지 않아요. |
| cause | 완벽하게 하지 못할 바엔 시작을 미루는 게 편해서 그런 것 같아요. | 예전에 말실수했던 기억이 자꾸 떠올라서 그런 것 같아요. | 낮 동안 정리 못 한 걱정거리들이 밤에 한꺼번에 떠올라서 그런 것 같아요. |
| behavior | 마감이 코앞에 닥쳐야 겨우 시작하고, 그전까진 계속 딴짓을 해요. | 사람 만나는 자리를 이런저런 핑계로 피하게 돼요. | 잠들려고 누워서도 계속 휴대폰을 들여다보게 돼요. |
| duration | 한 학기 내내 그랬고, 마감 있는 일마다 매번 반복돼요. | 두어 달 전부터 사람 만난 다음 날마다 그래요. | 3주 정도 됐고, 거의 매일 밤 그래요. |
| impact | 마감 직전에 몰아서 하다 보니 결과물 퀄리티도 떨어지고 스트레스도 심해져요. | 만남 자체가 부담스러워져서 약속을 점점 줄이게 돼요. | 다음 날 계속 피곤해서 일에 집중이 잘 안 돼요. |
| relationship | 팀원들한테 계속 민폐를 끼치는 것 같아서 눈치가 보여요. | 친했던 친구들과도 점점 연락이 뜸해졌어요. | 예민해져서 가족들한테 괜히 짜증을 내게 돼요. |
| coping | 할 일 목록을 만들어봤는데 그때뿐이고 오래가지 않아요. | 만나기 전에 할 말을 미리 연습해봤는데 크게 도움은 안 됐어요. | 자기 전에 휴대폰을 안 보려고 해봤는데 잘 지켜지지 않아요. |
| goal | 미리미리 시작해서 여유 있게 마무리하고 싶어요. | 만남 후에 곱씹지 않고 편하게 넘길 수 있으면 좋겠어요. | 누우면 금방 잠들 수 있으면 좋겠어요. |
| self_message | 완벽하지 않아도 괜찮으니 일단 시작해보자고 말해주고 싶어요. | 그 정도 실수는 아무도 신경 안 쓴다고 말해주고 싶어요. | 오늘 하루도 충분히 애썼다고, 이제 마음 편히 쉬어도 된다고 말해주고 싶어요. |

## 범위 밖

- 백엔드 변경 없음 (순수 프론트 UI 텍스트 변경).
- `values`/`done` 단계, `rapport` 단계는 `pending_slot`이 비어 있으므로 기본값(situation 행)을 그대로 노출한다 — 별도 문구를 만들지 않는다.
- 자동화 테스트 추가는 다루지 않는다 (순수 정적 텍스트 매핑이라 수동 확인으로 충분하다고 판단).

## 검증 방법

프런트 개발 서버에서 상담 화면에 진입해 각 슬롯 질문 단계마다 예시 칩 3개의 문구가 위 표와 일치하는지, 클릭 시 입력창에 정확히 채워지는지 수동으로 확인한다.
